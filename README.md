
# Swift To-Do List

A simple iOS To-Do List application developed using **Swift and SwiftUI**. This project serves as a starter application for learning GitHub Actions, CI/CD automation, and DevSecOps practices.

## Features

- **Add Tasks:** Create new tasks with a description.
- **Complete Tasks:** Mark tasks as completed or incomplete.
- **Delete Tasks:** Remove tasks from the list.
- **Task List:** View and manage tasks through a simple interface.

## Getting Started

1. Clone or download this repository.
2. Open `TodoList.xcodeproj` in Xcode.
3. Select an available iOS Simulator.
4. Click **Run** or press `Cmd + R` to launch the application.

## Unit Testing

The project includes basic unit tests using XCTest to verify:

- Adding a new task.
- Marking a task as completed.
- Deleting a task.

To run the tests in Xcode, press `Cmd + U`.

## GitHub Actions Activity

This project will be used for a hands-on DevSecOps activity where students create a GitHub Actions YAML workflow to automate:

1. **Build:** Compile the Swift application.
2. **Unit Test:** Execute automated XCTest tests.
3. **Security Scan:** Analyse Swift source code using GitHub CodeQL.

Students will construct and execute their own CI workflow using GitHub Actions.
